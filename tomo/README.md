# 心境水彩日記 (Tomo)

一款以語音記錄情緒的水彩暈染日記 App，透過聲音捕捉當下心境，並即時生成對應的水彩視覺效果。

## 特色功能

- **語音記錄**：使用 Web Speech API 進行即時中文語音轉文字
- **情緒偵測**：分析語音內容，辨識 10 種情緒（平靜、快樂、興奮、悲傷、焦慮、憤怒、感激、疲倦、溫柔、孤獨）
- **水彩動畫**：根據偵測到的情緒，即時生成對應色彩的水彩暈染效果
- **日記管理**：儲存每篇語音日記，含水彩畫面快照、文字內容與情緒標記

## 使用方式

直接在瀏覽器開啟 `voice-diary.html`，無需安裝任何套件。

> 建議使用 Chrome 或 Safari，語音辨識功能目前不支援所有瀏覽器。

### 操作流程

1. 點擊麥克風按鈕開始錄音
2. 對著麥克風說話，即時看到語音轉文字與水彩動畫反應
3. 點擊停止後，按「儲存」保留這篇日記
4. 點擊「日記簿」查看所有記錄

## 技術架構

純前端，零依賴，單一 HTML 檔案。

- **語音辨識**：Web Speech Recognition API（繁體中文）
- **水彩視覺**：Canvas 2D API，自製 Perlin-like 有機形狀生成
- **音量視覺化**：Web Audio API
- **字型**：Noto Serif TC、Playfair Display（Google Fonts）
