04 動畫規格 · Animation Spec
頁面層級 · Page-level Transitions
元件相關動畫已移至各元件頁面
Onboarding 頁切換
transform: translateX(−100vw × n) / transition: .45s cubic-bezier(.4,0,.2,1)
ob-track 整條水平位移；easing 為 Material Design standard curve，帶有輕微的加速/減速感
Reflection Panel 滑入
transform: translateY(100%) → translateY(0) / transition: .45s cubic-bezier(.4,0,.2,1)
同 Done Sheet 滑入。全域共用相同 easing 和 duration，保持動畫語言一致
View 切換（各主畫面）
opacity: 0 → 1 / transition: .4s / pointer-events 同步切換
Onboarding → Auth → Loading → Record → Diary 各層以 opacity 淡入淡出；pointer-events:none 防止隱藏層被點擊
Reflection 浮現（錄音中）
opacity: 0 → 1 / transition: .8s ease / animation-delay: 1400ms
偵測到低落情緒後，過去日記片段靜靜浮現。延遲 1.4 秒避免打擾使用者說話節奏
Onboarding Wave（說明頁插圖）
@keyframes waveEx { 0% opacity:.65 scale(.8) → 100% opacity:0 scale(1) }
duration: 2.4s ease-out infinite / delay: 0s / 0.55s / 1.1s / 1.65s（4 圈各自錯位）
麥克風周圍的聲波圈，4 個 div 依次以相同 keyframe 播放，製造向外擴散感
情緒色切換（水彩 Canvas）
Canvas blob color 以 1–2 秒漸變（不硬切）
LLM 回傳新 { emotion, intensity } 時，新的水彩 blob 以新色系生成，舊 blob 自然淡出；視覺上不會突然切色
